Unit 1: Introduction & Process Management

OS types, structure, services, system calls, boot, process, threads, IPC, CPU scheduling

1.1 Operating System: Definition aur Types

Definition Operating System (OS) ek system software hai jo computer hardware aur user ke beech interface ka kaam karta hai. Ye hardware resources (CPU, memory, I/O, disk) ko manage karta hai aur application programs ko run karne ka environment deta hai.
Fig 1.1: Computer system ka layered view. OS beech mein "manager" hai.

OS ke Goals aur Functions

  • Convenience: computer ko use karna aasaan banana.
  • Efficiency: hardware resources ka best use (CPU idle na rahe).
  • Resource Manager: CPU time, memory space, file storage, I/O devices ko programs mein baantna.
  • Control Program: programs ki galat/illegal activity rokna.

Types of Operating Systems

1. Batch Operating System

Similar jobs ko ek batch mein jama karke operator computer ko ek saath dete hain. User aur computer ke beech koi direct interaction nahi hota.

  • Fayde: bade repetitive jobs ke liye acchha, CPU ka use better.
  • Nuksan: interactive nahi, ek job atak jaye to baaki wait karte hain, debugging mushkil, CPU idle hota hai jab job I/O mein hai.
  • Example: payroll, bank statements, IBM early mainframes.
Fig 1.2: Batch system flow
2. Multiprogramming Operating System

Memory mein ek se zyada programs ek saath rakhe jate hain. Jab ek program I/O ke liye wait karta hai, CPU turant dusre program ko mil jata hai. Isse CPU utilization badhta hai.

Fig 1.3: Multiprogramming: memory mein multiple jobs
Degree of Multiprogramming = memory mein ek time par kitne processes hain. Zyada degree = CPU utilization zyada.
3. Time Sharing (Multitasking) Operating System

Multiprogramming ka extension. CPU time ko chhote time slices (quantum) mein baant kar har user/process ko baari-baari se diya jata hai.

MultiprogrammingTime Sharing
Goal: CPU utilization maximizeGoal: response time minimize
Switch tab hota hai jab process I/O ke liye wait kareSwitch timer interrupt (time quantum khatam) par hota hai
Interactive nahi hona zaruriInteractive hota hai
4. Parallel (Multiprocessor / Tightly Coupled) Systems

Ek hi computer mein do ya zyada CPUs hote hain jo common memory aur bus share karte hain.

  • Asymmetric Multiprocessing (AMP): ek master CPU baaki slave CPUs ko kaam deta hai.
  • Symmetric Multiprocessing (SMP): sab CPUs barabar hain, modern systems (Linux, Windows) SMP use karte hain.
5. Distributed Operating System (Loosely Coupled)

Alag-alag computers (nodes) network se jude hote hain. Har ka apna memory aur clock hota hai.

6. Real-Time Operating System (RTOS)
  • Hard Real-Time: deadline miss = system failure (pacemaker, airbag, missile control).
  • Soft Real-Time: deadline miss = quality drop (video streaming, gaming).

1.3 Operating System Components aur Services

Process Management, Memory Management, File Management, I/O Management, Secondary Storage, Networking, Protection, Shell.

1.4 System Calls, System Programs aur System Boot

System Call User mode se kernel mode mein OS ki services maangne ka interface (fork, read, write, open, close, exit).

Boot Process: Power ON → POST → BIOS/UEFI → MBR (Boot Loader / GRUB) → Kernel Load → init (PID 1) → Services → Login Screen.

1.5 Process Concept aur Process Scheduling

Process: Program in execution. PCB (Process Control Block) holds: PID, State, PC, Registers, Memory info, Priority.

States: New, Ready, Running, Waiting, Terminated.

1.6 Cooperating Process aur Interprocess Communication (IPC)

Shared Memory: Fast, direct memory share, synchronization required by programmer.

Message Passing: Kernel managed, send() and receive(), suitable for distributed systems.

1.7 Threads (Lightweight Processes)

User-Level Threads (ULT) vs Kernel-Level Threads (KLT). Models: Many-to-One, One-to-One, Many-to-Many.

1.8 CPU Scheduling

Formulas: Turnaround Time (TAT) = Completion Time (CT) − Arrival Time (AT). Waiting Time (WT) = TAT − Burst Time (BT).
